# Frontend dizayn tamoyillari

Har bir loyihaga kichik studiyaning dizayn rahbari sifatida yondash — shablonga o'xshamaydigan, o'ziga xos vizual identifikatsiya yarat.

## Asosiy tamoyillar

1. **Subyektga bog'la** — dizaynni mahsulotning o'z dunyosidan (materiallar, atributlar, tili) chiqar, umumiy shablondan emas.
2. **Hero = thesis** — sahifani subyektning eng xarakterli narsasi bilan och. "Katta raqam + gradient accent" — bu shablon javob, faqat chindan eng yaxshi variant bo'lsagina ishlat.
3. **Tipografika = shaxsiyat** — display va body shriftlarni har loyihada takrorlanmaydigan qilib tanla.
4. **Struktura = ma'lumot** — raqamlash (01/02/03), dividerlar kontent haqida haqiqiy narsani ifodalasin, bezak bo'lmasin.
5. **Harakat (motion)** — maqsadli ishlat; ortiqcha animatsiya "AI yasagan" tuyg'usini beradi.

## Qochish kerak bo'lgan klishelar

AI dizayni odatda 3 ta klishega tushadi:

- Krem fon (`#F4F1EA`) + kontrast serif + terracotta accent (`#D97757` — bu Anthropic'ning o'z rangi, "tell" bo'lib ko'rinadi)
- Deyarli qora fon + bitta kislotali yashil/vermilion accent
- Gazeta uslubidagi hairline chiziqlar, 0 border-radius, zich ustunlar

## Jarayon

1. Brainstorm
2. Token tizimi (4-6 rang, 2+ shrift, layout, signature element)
3. Brief'ga solishtirib tanqid
4. Kod yozish
5. Yana tanqid

## Restraint

Jasoratni bitta joyga sarfla (signature element), qolganini tinch tut. Chanel maslahati — uydan chiqishdan oldin bitta aksessuarni yechib qo'y.

## Yozuv (copy)

So'zlar ham dizayn materiali. Faol ovoz, foydalanuvchi tilida ("Save changes", "Submit" emas), izchil vocabulary.
